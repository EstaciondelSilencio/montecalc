# MonteCalc function reference

_Generated by tools/gen_functions.py from the same table as the add-in._

Function names follow the MC FLO user guide. Arguments in [brackets] are optional; separate arguments with `;`.
Functions returning arrays (n x m) are entered as array formulas (Ctrl+Shift+Enter).

## Model functions: time series

| Function | Description | Notes |
|---|---|---|
| `FLOsimula_TemporalS_ARmodel(Start; Weight; StDeviation; UseBefore; Variable_name; [Number]; [Min]; [Max]; [Round])` | Input variable: AR(1) process around the level Start. | The (correlated) random number drives the noise of each iteration; UseBefore = 1 restarts every iteration at Start. |

| `FLOsimula_TemporalS_ARCHmodel(Omega; Alpha; Variable_name; [Number]; [Min]; [Max]; [Round])` | Input variable: ARCH(1) process (mean 0, non-constant volatility). | The (correlated) random number drives the noise of each iteration; UseBefore = 1 restarts every iteration at Start. |
| `FLOsimula_TemporalS_WPmodel(Start; Drift; Mu; StDeviation; UseBefore; Variable_name; [Number]; [Min]; [Max]; [Round])` | Input variable: Wiener process (geometric Brownian motion); StDeviation is optional. | The (correlated) random number drives the noise of each iteration; UseBefore = 1 restarts every iteration at Start. |

## Information and settings

| Function | Description | Notes |
|---|---|---|
| `fMC_Iterations()` | Number of iterations of the last simulation. |  |
| `fMC_Best(Value)` | Confidence level of the best case; with Value in [0,1] the best case is set dynamically to Value. |  |
| `fMC_Real(Value)` | Confidence level of the real case; with Value in [0,1] the real case is set dynamically to Value. |  |
| `fMC_Worst(Value)` | Confidence level of the worst case; with Value in [0,1] the worst case is set dynamically to Value. |  |
| `fMC_GetInputName(Pos)` | Input variable at position Pos. |  |
| `fMC_GetUserDefinedInputName(Pos)` | User-defined input variable at position Pos. |  |
| `fMC_GetOuputName(Pos)` | Output variable at position Pos (name as spelled in the manual). |  |
| `fMC_GetOutputName(Pos)` | Output variable at position Pos. |  |
| `fmc_Name(Name)` | Name of the MC FLO variable in the given cell. |  |
| `fMC_Bin(Value)` | Sets the number of histogram columns used by all histograms and functions (global). |  |
| `fMC_SimulaOn(Value)` | Workbook simulation mode: TRUE shows random values after each recalculation, FALSE the expected values. |  |
